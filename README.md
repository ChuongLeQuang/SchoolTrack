# SchoolTrack

**SchoolTrack** là giải pháp phần mềm quản lý trung tâm đào tạo toàn diện. Hệ thống giúp số hóa vòng đời sinh viên, cung cấp công cụ trực quan để quản lý hồ sơ, đối chiếu dữ liệu học phí từ kế toán, và tự động hóa việc lên kế hoạch mở lớp dựa trên chỉ tiêu (Min/Max).

## Môi trường ảo (.venv)
Nếu bạn đã khởi tạo kèm `.venv`, hãy kích hoạt nó bằng lệnh sau:
- **Windows**: `.\.venv\Scripts\activate`
- **Mac/Linux**: `source .venv/bin/activate`
